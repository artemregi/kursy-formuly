# Курсы – база знаний контент-завода Тёма в тему

- `Формула_контента/` – курс «Формула контента»: уроки `lesson*_text.txt`, весь курс одним файлом `full_course.txt`.
- `Формула_запуска/` – курс «Формула запуска»: модули 01–08 (введение, продукт на 1 млн, быстрый старт, поиск клиентов, продюсер, контент, прогрев, продажи), оглавление в `Формула_запуска/README.md`.

Любой пост, сценарий или план прогрева пишется по этим двум курсам, урок указывается в строке `> источник:`.
Оригиналы на Mac: `~/Desktop/ТЕМА-В-ТЕМУ/База_знаний_Тёма_в_тему/01_курс_Формула_контента`, `~/Movies/TV/Media.localized/COURSE_KNOWLEDGE_BASE/Формула_запуска`.
