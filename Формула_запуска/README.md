# Формула запуска — Миша Христосенко

## О курсе

Курс по запуску онлайн-курсов и наставничества через Instagram. Автор — Миша Христосенко, продюсер и основатель «Формулы запуска». Курс охватывает полный цикл: от понимания бизнес-модели до системного поиска клиентов.

|---|--------|-------:|---------------|
| 1 | [Введение](MODULE_01_Введение/) | 6 | Бизнес-модель запусков, путь эксперта vs продюсера |

## Последовательность прохождения

1. **Модуль 1 → Модуль 2 → Модуль 3 → Модуль 4 → Модуль 5 → Модуль 6 → Модуль 7 → Модуль 8** — именно в таком порядке
2. Модуль 1 даёт общее понимание, модуль 2 — продукт, модуль 3 — механику запуска, модуль 4 — поиск клиентов
3. Модули 5–8 — углублённые темы: продюсирование, контент, прогрев, продажи
4. Урок «Введение в запуски» (Модуль 1) является живым примером лид-магнита (разбирается в Модуле 3)

## Ключевые концепции курса

- **Запуск** — проверенная технология привлечения тысяч клиентов на онлайн-курс
- **Продюсер** — человек, который помогает экспертам запускать курсы за процент от продаж
- **Лид-магнит** — бесплатный ценный материал, который прогревает к покупке (= «свидание»)
- **Прогрев** — серия сторис/контента, готовящая аудиторию к покупке
- **Твёрдый кейс** — один яркий результат, который меняет всё
- **Воронка запуска** — контент → прогрев → лид-магнит → директ → Zoom → продажа
