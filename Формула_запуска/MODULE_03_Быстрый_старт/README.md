# Модуль 3 — Быстрый старт

## Цель модуля

Дать конкретную пошаговую схему запуска в блоге: от создания лид-магнита до закрытия продаж через Zoom.

## Что нужно знать перед началом

- Модуль 1 (Введение) — понимание модели
- Модуль 2 (Продукт) — готовый концепт продукта

## Уроки

### 1. [Сценарий лид-магнита](01_Сценарий_лид_магнита.md)

- **О чём:** Что такое лид-магнит, зачем он нужен и по какой структуре снимать продающее видео
- **Основные темы:**
  - Лид-магнит = «свидание» перед продажей
  - Резкий шаг убивает конверсию
  - Виды лид-магнитов: видео, курс, вебинар, гайд
  - Почему видео — лучший формат для старта
  - Структура продающего видео (файл-приложение к уроку)
  - Лид-магнит должен быть и обучающим, и продающим
- **Задание:** Смотреть пример ролика как продюсер, с открытой схемой рядом
- **Связанные уроки:** Модуль 1, Урок 1 (является примером лид-магнита)
- **Скриншоты:** `screenshots/02_Лидмагнит/`

### 2. [Открываем продажи в блоге — полная схема запуска](02_Схема_запуска_в_блоге.md)

- **О чём:** Полная 20-дневная схема запуска в Instagram через сторис + директ + Zoom
- **Основные темы:**
  - Воронка: плюсики в директ → переписка → Zoom-созвон → продажа
  - Реалистичная цель первого запуска: 50–100 плюсиков → 15–20 созвонов → 3–7 продаж → 200–300К
  - День 10: анонс идеи продукта
  - День 11: презентация продукта (наставничество)
  - Дни 14–15: отработка возражений
  - День 16: последний шанс
  - Бонус: Zoom-разборы
  - **Единая схема запуска (4 этапа):** контент → прогрев+лид-магнит → анонс продукта → разборы
- **Это ключевой урок модуля** — содержит полную пошаговую схему
- **Скриншоты:** `screenshots/04_Схема_запуска/` — включая схему 4 этапов запуска
