# Модуль 2 — Продукт на 1 млн$

## Цель модуля

Научить создавать мощный, хорошо продаваемый онлайн-продукт по 8-шаговой системе.

## Что нужно знать перед началом

- Модуль 1 (Введение) — понимание бизнес-модели запусков

## Контекст

В имеющихся видео представлены шаги 7 и 8 из 8-шаговой системы создания продукта. Шаги 1–6 упоминаются в recap:

1. Изучить аудиторию (для кого)
2. Большое обещание
3. Программа курса
4. Что «по итогу» у человека
5. Формат курса (длительность, поддержка)
6. Цены и тарифы
7. **Фишки вау-эффекта** ← этот урок
8. **Болеутолители** ← этот урок
